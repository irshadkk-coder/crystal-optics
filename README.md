# OptiStore Pro

A modern business website for an optical store, built with React, TypeScript, Vite, and Tailwind CSS.

The website showcases optical products and services, allows customers to book appointments, provides contact information, and includes a virtual try-on experience using the device camera.

## Features

* Modern responsive design
* Product and service showcase
* Appointment booking
* Contact and location information
* Admin dashboard
* Camera-based virtual try-on
* Mobile-friendly interface

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* MediaPipe

## Prerequisites

* Node.js 18+
* npm

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

The production files are generated in:

```text
dist/
```

Preview the production build locally:

```bash
npm run preview
```

## Deployment

This project can be deployed to:

* Vercel
* Netlify
* GitHub Pages
* Any static hosting provider

## Notes

* Virtual try-on features require HTTPS in production.
* Users must grant camera permissions to use virtual try-on.
* External assets and CDN resources should remain accessible after deployment.
